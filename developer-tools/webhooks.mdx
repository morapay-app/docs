Morapay sends **outbound webhooks** when payments, payouts, and other resources change state.

## Manage endpoints (merchant API)

| Action | Route |
|--------|--------|
| List | `GET /v2/webhooks` |
| Create | `POST /v2/webhooks` |
| Update | `PATCH /v2/webhooks/{id}` |
| Delete | `DELETE /v2/webhooks/{id}` |
| List deliveries | `GET /v2/deliveries` |
| Retry delivery | `POST /v2/deliveries/{id}/retry` |

Create endpoints with signed requests ([Authentication](/getting-started/authentication)). Store the endpoint **secret** when shown; it is required to verify deliveries.

## Event payload

Deliveries are `POST` requests to your URL with JSON body and headers:

| Header | Meaning |
|--------|---------|
| `Morapay-Event` | Event type |
| `Morapay-Delivery` | Delivery log id |
| `Morapay-Signature` | `sha256=<hex>` HMAC of the raw body |

```json
{
  "id": "evt_01",
  "type": "payment_link.paid",
  "created": "2026-11-17T20:00:00.000Z",
  "data": {}
}
```

## Verify signatures

Sign the **raw request body string** with HMAC-SHA256 using the endpoint secret. Compare to `Morapay-Signature`:

<CodeGroup>

```javascript Node.js
import { createHmac, timingSafeEqual } from "node:crypto";

export function verifyMorapayWebhook(rawBody, signatureHeader, secret) {
  const expected = createHmac("sha256", secret).update(rawBody, "utf8").digest("hex");
  const provided = signatureHeader.replace(/^sha256=/i, "").trim();
  try {
    const a = Buffer.from(provided, "hex");
    const b = Buffer.from(expected, "hex");
    return a.length === b.length && timingSafeEqual(a, b);
  } catch {
    return false;
  }
}
```

```bash cURL (test vector)
# expected = HMAC-SHA256(secret, rawBody) as lowercase hex
# header: Morapay-Signature: sha256=<expected>
```

</CodeGroup>

<Note>
  Parse JSON only **after** verification. Re-serialized JSON will not match the signature.
</Note>

## Reliability

- Respond with `2xx` quickly; process asynchronously.
- Failed deliveries appear in `GET /v2/deliveries` and can be retried with `POST /v2/deliveries/{id}/retry`.
