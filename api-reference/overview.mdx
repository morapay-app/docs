The **Morapay v2 API** is the HTTP integration surface for payments, ramp, payouts, and merchant account management.

## Base URL

```
https://api.morapay.io
```

All paths in this reference are rooted at `/v2`.

## Authentication

Signed merchant requests send:

- `Morapay-Key`
- `Morapay-Timestamp`
- `Morapay-Signature` (`v1=<hex>`)

See [Authentication](/getting-started/authentication).

## Response shape

| Outcome | Shape |
|---------|--------|
| Success | `{ "data": …, "meta": { "request_id" } }` |
| List | `{ "data": { "items": […], "meta": { "page", "limit", "total" } } }` |
| Error | `{ "error": { "code", "message", … }, "meta": { "request_id" } }` |

Details: [Responses and errors](/concepts/responses-and-errors).

## Resource map

| Area | Prefix | Guide |
|------|--------|--------|
| Coverage snapshots | [Coverage](/reference/coverage) tables (not separate catalog routes) | Countries, chains, tokens |
| Quotes & rates | `/v2/quotes`, `/v2/rates` | [Quotes and ramp](/guides/quotes-and-ramp) |
| Ramp | `/v2/buys`, `/v2/sells` | [Quotes and ramp](/guides/quotes-and-ramp) |
| Links & checkout | `/v2/links`, `/v2/checkouts`, `/v2/payments/{payment_id}/confirm` | [Payment links](/guides/payment-links), [Checkouts](/guides/checkouts-and-payments) |
| Payouts | `/v2/payouts`, `/v2/schedules`, `/v2/recipients` | [Payouts](/guides/payouts) |
| Bridge & swap | `/v2/bridges`, `/v2/swaps`, bridge quotes on `POST /v2/quotes` (`kind: bridge`) | API reference |
| Merchant account | `/v2/keys`, `/v2/webhooks`, `/v2/transactions`, … | OpenAPI tags `merchant_*` |
| System | `GET /v2/health` | [Environments](/getting-started/environments) |

Operation-level schemas are generated from the OpenAPI document bundled with this site (`openapi/v2.openapi.json`).
