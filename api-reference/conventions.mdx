## Paths

- Resources use **plural nouns**: `/v2/links`, `/v2/payouts`.
- Actions on a resource use **`POST /v2/{resource}/{id}/{verb}`** — e.g. `/v2/buys/{id}/cancel`, `/v2/payouts/{payout_id}/cancel`.
- Public customer flows live under **`/v2/public/...`**.

## Money

Amounts are **decimal strings** in major units (e.g. `"100.00"` GHS). BTC uses integer satoshis where noted in OpenAPI. Never send IEEE floats.

## Pagination

List endpoints return:

```json
{
  "data": {
    "items": [],
    "meta": { "page": 1, "limit": 20, "total": 42 }
  }
}
```

Query with `page` and `limit` unless the route documents cursor fields.

## Idempotency

When `Idempotency-Key` is required, send a unique key per logical operation. Reuse the key only when retrying the **identical** body after a network failure.

## Request ID

Successful and failed responses may include `meta.request_id`. Quote it when contacting support.

## Errors

Errors use stable `error.code` values (snake_case). See [Error handling](/errors/error-handling) and generated error code pages.
