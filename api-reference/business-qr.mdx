---
title: "Business QR and pay pages"
description: "Open-amount business checkout and QR configuration."
---

Business QR lets customers pay any amount at a stable `/pay/:businessSlug` URL.

Base path: `/api/v1/merchant`

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/qr` | Get QR and pay page config |
| `POST` | `/qr` | Update QR branding and settings |
| `GET` | `/payment-requests` | List legacy payment requests |
| `POST` | `/payment-requests` | Create payment request |
| `GET` | `/payment-requests/:id` | Get payment request |

## Get QR config

`GET /api/v1/merchant/qr`

<RequestExample>

```bash cURL
curl -s "https://api.morapay.io/api/v1/merchant/qr" \
  -H "Morapay-Key: $MORAPAY_PUBLIC_KEY" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE"
```

</RequestExample>

<ResponseExample>

<CodeGroup>

```json 200 OK
{
  "success": true,
  "data": {
    "businessSlug": "acme-coffee",
    "enabled": true,
    "defaultCurrency": "GHS",
    "checkoutUrl": "https://checkout.morapay.io/pay/acme-coffee"
  }
}
```

```json 401 Unauthorized
{
  "success": false,
  "error": "Invalid request signature.",
  "code": "auth.signature.mismatch",
  "requestId": "req_qr401"
}
```

</CodeGroup>

</ResponseExample>

## Update QR config

`POST /api/v1/merchant/qr`

Update slug visibility, default currency, and display options per your dashboard schema.

<RequestExample>

```bash cURL
curl -s -X POST "https://api.morapay.io/api/v1/merchant/qr" \
  -H "Content-Type: application/json" \
  -H "Morapay-Key: $MORAPAY_PUBLIC_KEY" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE" \
  -d '{ "enabled": true, "defaultCurrency": "GHS" }'
```

</RequestExample>

<ResponseExample>

<CodeGroup>

```json 200 OK
{
  "success": true,
  "data": {
    "enabled": true,
    "defaultCurrency": "GHS"
  }
}
```

```json 400 Bad Request
{
  "success": false,
  "error": "Invalid body.",
  "code": "request.invalid",
  "requestId": "req_qr400"
}
```

</CodeGroup>

</ResponseExample>

## Payment requests

Legacy REQUEST-type flows for ad hoc invoices.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/payment-requests` | List |
| `POST` | `/payment-requests` | Create |
| `GET` | `/payment-requests/:id` | Detail |

<RequestExample>

```bash cURL
curl -s -X POST "https://api.morapay.io/api/v1/merchant/payment-requests" \
  -H "Content-Type: application/json" \
  -H "Morapay-Key: $MORAPAY_PUBLIC_KEY" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE" \
  -d '{ "amount": 50, "currency": "GHS", "description": "Table 4" }'
```

</RequestExample>

<ResponseExample>

<CodeGroup>

```json 201 Created
{
  "success": true,
  "data": {
    "id": "req_uuid",
    "amount": 50,
    "currency": "GHS",
    "status": "PENDING"
  }
}
```

```json 404 Not Found
{
  "success": false,
  "error": "Payment request not found.",
  "code": "resource.not_found",
  "requestId": "req_pr404"
}
```

</CodeGroup>

</ResponseExample>

## Common errors

| Code | HTTP | Cause |
|------|------|-------|
| `resource.not_found` | 404 | Unknown request id |
| `links.slug.duplicate` | 409 | Business slug conflict |
| `request.invalid` | 400 | Invalid body |
| `auth.signature.mismatch` | 401 | Invalid signed request |
