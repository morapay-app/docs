---
title: "Claims"
description: "Merchant claim links and public verify or redeem flows."
---

**Claims** let recipients pull funds through a shareable link. Merchants create and list claims on **`/v2/claims`**; end users interact through **`/v2/public/claims/{id}`** without API keys.

The OpenAPI file also exposes **`/v2/requests`** as a merchant **alias** for the same claim resources — prefer **`/v2/claims`** in new integrations. Full field lists: [OpenAPI](https://api.morapay.io/v2/openapi.json).

## Merchant API

| Method | Path | Purpose |
|--------|------|---------|
| `GET` | `/v2/claims` | List claims |
| `POST` | `/v2/claims` | Create a claim |
| `GET` | `/v2/claims/{id}` | Read one claim |

Signed requests use `https://api.morapay.io` with `Morapay-Key: pk_test_example` and signature path e.g. `/v2/claims`.

## Public API

| Method | Path | Purpose |
|--------|------|---------|
| `GET` | `/v2/public/claims/{id}` | Load claim metadata (`recipient_hint`, `source`) |
| `POST` | `/v2/public/claims/{id}/verify` | Verify recipient eligibility |
| `POST` | `/v2/public/claims/{id}/redeem` | Complete redemption |

Public `id` is a 16-character hex string in the contract.

## Create a claim

<CodeGroup>

```bash cURL
curl -s -X POST "https://api.morapay.io/v2/claims" \
  -H "Content-Type: application/json" \
  -H "Morapay-Key: pk_test_example" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE" \
  -d '{"amount":{"amount":"50.00","currency":"GHS"},"recipient_hint":"+233***4567"}'
```

```javascript Node.js
import { createHash, createHmac } from "node:crypto";

const headersFor = (path, body) => {
  const pk = "pk_test_example", sk = "sk_test_example";
  const ts = String(Math.floor(Date.now() / 1000));
  const bh = createHash("sha256").update(body, "utf8").digest("hex");
  const key = createHash("sha256").update(sk, "utf8").digest();
  const sig = createHmac("sha256", key).update(`${ts}.POST.${path}.${bh}`, "utf8").digest("hex");
  return { "Morapay-Key": pk, "Morapay-Timestamp": ts, "Morapay-Signature": `v1=${sig}`, "Content-Type": "application/json" };
};

const body = JSON.stringify({ amount: { amount: "50.00", currency: "GHS" }, recipient_hint: "+233***4567" });
const { data } = await fetch("https://api.morapay.io/v2/claims", { method: "POST", headers: headersFor("/v2/claims", body), body }).then((r) => r.json());
```

</CodeGroup>

## Public verify and redeem

```bash
curl -s "https://api.morapay.io/v2/public/claims/a1b2c3d4e5f67890"

curl -s -X POST "https://api.morapay.io/v2/public/claims/a1b2c3d4e5f67890/verify" \
  -H "Content-Type: application/json" \
  -d '{"phone_number":"+233201234567"}'

curl -s -X POST "https://api.morapay.io/v2/public/claims/a1b2c3d4e5f67890/redeem" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: redeem_a1b2_once" \
  -d '{"otp":"123456"}'
```

<Tip>
  If your SDK or dashboard still says **requests**, map it to **`/v2/claims`** — behavior matches the alias documented in OpenAPI.
</Tip>
