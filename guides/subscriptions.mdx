title: "Subscriptions"
description: "Billing plans and subscription lifecycle on the v2 merchant API."
---

Sell recurring access with **`/v2/plans`** and **`/v2/subscriptions`**. Customers can read a plan publicly at **`GET /v2/public/plans/{id}`** and subscription state at **`GET /v2/public/subscriptions/{id}`** when your product exposes those ids.

Merchant calls: `https://api.morapay.io`, headers `Morapay-Key: pk_test_example`, `Morapay-Timestamp`, `Morapay-Signature: v1=…` (sign paths like `/v2/plans` or `/v2/subscriptions/sub_01`).

Plan and subscription object fields are defined in [OpenAPI](https://api.morapay.io/v2/openapi.json).

## Plans

| Method | Path |
|--------|------|
| `GET` | `/v2/plans` |
| `POST` | `/v2/plans` |
| `GET` | `/v2/plans/{id}` |
| `PATCH` | `/v2/plans/{id}` |

## Subscriptions

| Method | Path |
|--------|------|
| `GET` | `/v2/subscriptions` |

| `POST` | `/v2/subscriptions/{id}/pause` |
| `POST` | `/v2/subscriptions/{id}/cancel` |

## Create a plan

<CodeGroup>

```bash cURL
curl -s -X POST "https://api.morapay.io/v2/plans" \
  -H "Content-Type: application/json" \
  -H "Morapay-Key: pk_test_example" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE" \
  -d '{"name":"Pro monthly","amount":{"amount":"199.00","currency":"GHS"},"interval":"month"}'
```

```javascript Node.js
import { createHash, createHmac } from "node:crypto";

function signedHeaders(method, path, body) {
  const pk = "pk_test_example", sk = "sk_test_example";
  const ts = String(Math.floor(Date.now() / 1000));
  const bh = createHash("sha256").update(body, "utf8").digest("hex");
  const key = createHash("sha256").update(sk, "utf8").digest();
  const sig = createHmac("sha256", key).update(`${ts}.${method}.${path}.${bh}`, "utf8").digest("hex");
  return { "Morapay-Key": pk, "Morapay-Timestamp": ts, "Morapay-Signature": `v1=${sig}` };
}

const planBody = JSON.stringify({ name: "Pro monthly", amount: { amount: "199.00", currency: "GHS" }, interval: "month" });
const plan = await fetch("https://api.morapay.io/v2/plans", {
  method: "POST",
  headers: { ...signedHeaders("POST", "/v2/plans", planBody), "Content-Type": "application/json" },
  body: planBody,
}).then((r) => r.json());
```

</CodeGroup>

## Start a subscription

```bash
curl -s -X POST "https://api.morapay.io/v2/subscriptions" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sub_2026-11-17_7f3a" \
  -H "Morapay-Key: pk_test_example" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE" \
  -d '{"plan_id":"pln_01","customer_email":"user@example.com"}'
```

<ResponseExample>

```json Subscription
{
  "data": { "id": "sub_01", "status": "active", "plan_id": "pln_01" },
  "meta": { "request_id": "req_1731810000006_g" }
}
```

</ResponseExample>

## Pause or cancel

```bash
curl -s -X POST "https://api.morapay.io/v2/subscriptions/sub_01/pause" \
  -H "Morapay-Key: pk_test_example" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE"

curl -s -X POST "https://api.morapay.io/v2/subscriptions/sub_01/cancel" \
  -H "Morapay-Key: pk_test_example" \
  -H "Morapay-Timestamp: $TIMESTAMP" \
  -H "Morapay-Signature: v1=$SIGNATURE"
```

<Tip>
  Use **`POST …/invoice`** when you need an on-demand charge outside the normal billing cycle; see OpenAPI for optional body fields.
</Tip>
