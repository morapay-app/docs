---
title: "Countries & fiat"
description: "Supported countries, settlement currencies, and fiat payment rails."
---

Morapay supports international crypto checkout and regional fiat rails. Country availability is stored in the Morapay API catalog and exposed at `GET /api/public/catalog/countries`.

<Note>
  Country availability changes over time. Use `GET /api/public/catalog/countries?supported=any` for the authoritative list before shipping checkout or payout UI.
</Note>

## Fiat at checkout (Moolre)

These fiat currencies accept **mobile money** and **virtual bank transfer** at checkout when Moolre is enabled for your environment:

- **GHS**
- **NGN**

## API

Full REST documentation: [Catalog API](/api-reference/catalog#countries) · [Fiat checkout API](/api-reference/fiat-checkout)

```bash
curl -s "https://api.morapay.io/api/public/catalog/countries?supported=any"
```

Filter with `?supported=fonbnk`, `paystack`, or `any`.
