Merchant **withdrawals** and **disbursement batch** recipients settle to local rails via Moolre (Ghana MoMo / bank, Nigeria bank) and Paystack (card markets, bank resolve).

## Withdrawal rails

| Rail | Country | Currency | Method | Bank code required |
| --- | --- | --- | --- | --- |
| Ghana mobile money | GH | GHS | MOBILE MONEY | — |
| Nigeria bank account | NG | NGN | BANK ACCOUNT | Yes |
| Ghana bank account | GH | GHS | BANK ACCOUNT | Yes |

## API

[Payout rails API](/api-reference/payout-rails) — signed Merchant API for banks, MoMo operators, and account resolve.

Fetch live lists from the Morapay API:

```bash
# Paystack banks (withdrawal / resolve)
curl -s "https://api.morapay.io/api/klyra/relay/paystack/banks?country=ghana"

# Moolre banks (Ghana / Nigeria commerce)
curl -s "https://api.morapay.io/api/moolre/banks?country=gha"

# Merchant payout rails
curl -s "https://api.morapay.io/api/v1/merchant/payout-rails/banks" \
  -H "Morapay-Key: pk_test_..." \
  -H "Morapay-Timestamp: ..." \
  -H "Morapay-Signature: v1=..."
```
