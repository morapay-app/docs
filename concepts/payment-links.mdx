title: "Payment links"
description: "Shareable checkout URLs backed by /v2/links."

A **payment link** is a stable slug or code that opens Morapay checkout for a configured amount and currency. Create and manage links with the merchant API at **`/v2/links`**.

## Lifecycle

1. `POST /v2/links` — define amount, currency, and presentation fields.
2. Share `https://checkout.morapay.io/{public_code}` with customers using the `public_code` from the link.
3. Customer checkout uses **`POST /v2/checkouts`** or the hosted commerce flow (see [Checkouts and payments](/guides/checkouts-and-payments)).
4. Listen for `payment_link.paid` (and related) on your [webhook](/developer-tools/webhooks) endpoint.

## Products

Attach catalog items with `product_id` when you maintain products via `GET/POST /v2/products` (OpenAPI).

## Minimum amounts

Fixed amount links must be worth at least $1 USD equivalent at creation, converted at the current rate. Open amount links with no `amount` have no minimum.

When the amount is below the minimum, `POST /v2/links` returns HTTP `422` with top level code `request.validation_failed`. Inspect `error.details` for `{ "field": "amount", "code": "below_minimum" }`.
