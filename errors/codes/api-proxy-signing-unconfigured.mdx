**Code:** `api.proxy.signing_unconfigured`  
**HTTP:** `503 Service Unavailable`

## What happened

The Morapay API could not complete the request due to rate limits, connectivity, or infrastructure.

## Safe message

> Our payment service is temporarily unavailable. Please try again shortly.

Use `err.safeMessage` or `err.displayMessage` in customer UI, not `err.message`.

## Why this happened

The Morapay API cannot sign outbound requests.

## How to fix it

Configure platform API signing credentials on your server.

## UI hint

| Field | Value |
|-------|-------|
| `severity` | `critical` |
| `placement` | `toast` |
| `actionText` | `Retry` |

## Programmatic handling

```typescript
import { MorapayApiError, isMorapayError } from "@morapay/sdk";

catch (err) {
  if (isMorapayError(err) && err.code === "api.proxy.signing_unconfigured") {
    console.error(err.format());
    // Customer UI: err.displayMessage ?? err.safeMessage
    // Support: err.requestId
  }
}
```
