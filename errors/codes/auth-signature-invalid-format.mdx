**Code:** `auth.signature.invalid_format`  
**HTTP:** `401 Unauthorized`

## What happened

The API rejected the request during authentication before your route handler ran.

## Safe message

> We could not verify this request. Please try again later.

Use `err.safeMessage` or `err.displayMessage` in customer UI, not `err.message`.

## Why this happened

Morapay-Signature is not in the required v1=<hex> format.

## How to fix it

Prefix the HMAC digest with v1= as documented. The SDK formats this automatically.

## UI hint

| Field | Value |
|-------|-------|
| `severity` | `critical` |
| `placement` | `toast` |


## Programmatic handling

```typescript
import { MorapayAuthenticationError, isMorapayError, MorapayErrorCode } from "@morapay/sdk";

catch (err) {
  if (isMorapayError(err) && err.code === MorapayErrorCode.AuthSignatureInvalidFormat) {
    console.error(err.format());
    // Customer UI: err.displayMessage ?? err.safeMessage
    // Support: err.requestId
  }
}
```
